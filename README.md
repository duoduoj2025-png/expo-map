# 大会逛展地图 H5

糖果色等距微缩风格的展会地图 H5：A/B/C 三个场馆 → 每馆 10 个区域 → 每区域 10 个展位，层层递进的地图交互。

## 访问

本仓库已开启 GitHub Pages，直接访问：

**https://<你的用户名>.github.io/<仓库名>/**

## 本地预览

直接用浏览器打开 `index.html` 即可，零依赖、单文件、移动端适配。

## 技术说明

- 纯 HTML + CSS + JS 单文件实现，无任何外部依赖
- 等距（isometric）地图用 DOM + 内联 SVG 菱形地块拼合
- 交互：三层下钻 + 面包屑导航、展位详情弹层、拖拽平移、入场弹跳动画
